# EvidenceTrace 文献研读助手

传智杯 AI 创新应用挑战赛作品。它把论文阅读组织成一个可核验闭环：**提问 → 跨语言检索 → 回答 → 检查证据 → 返回原文**。

在线体验：[cqkkl.github.io/paper-rag-assistant](https://cqkkl.github.io/paper-rag-assistant/)

## 为什么值得做

普通 AI 阅读工具常给出一段“看起来正确”的答案，却很难快速确认它是否来自原文。本项目不把生成答案当作终点，而是：

- 左侧原文、右侧可编辑译文，支持划词高亮与同步阅读；
- 中文问题可扩展为英文学术检索词，减少跨语言漏检；
- 使用 BM25 风格评分在分页文本块中召回证据；
- 回答只允许引用本轮召回页，生成后再次校验链接；
- 每条回答展示可点击证据卡，一键返回对应原文页；
- PDF、笔记、译文和对话默认保存在当前浏览器。

## 30 秒评审体验

1. 打开在线网站。
2. 点击首页的“**一键体验评审样例**”，无需 API Key。
3. 在“双语精读”查看左右对照，选择原文句子进行高亮并修改译文。
4. 进入“文献问答”，展开预置回答下的“检索证据”。
5. 点击证据卡，验证页面是否跳回对应双语原文。

样例论文和评测数字均为原创合成内容，只用于展示产品交互，不冒充真实研究结果。

## 10 分钟本地复现

### 1. 环境

- Node.js 20 或更高版本
- npm 10 或更高版本
- Chrome、Edge 或 Firefox 的较新版本

### 2. 安装和启动

```bash
git clone https://github.com/cqkkl/paper-rag-assistant.git
cd paper-rag-assistant
npm install
npm run dev
```

按终端提示打开本地地址，直接点击“一键体验评审样例”即可完成无网络演示。

### 3. 体验真实 AI 能力（可选）

在左侧“API 设置”中填写自己的 DeepSeek API Key。Key 默认只保留在当前会话；用户主动勾选后才会长期保存在本浏览器。随后上传可搜索的 PDF，即可使用翻译、摘要、问答、笔记和多论文对比。

### 4. 生产检查

```bash
npm run typecheck
npm run lint:eslint
npm run build
```

构建产物位于 `dist/client`。GitHub Pages 部署使用仓库名作为基础路径。

## 系统流程

```text
PDF
 ├─ 分页解析与学术版面重建 ──> 双语精读 / 高亮 / 译文修订
 └─ 重叠文本切块
       ↓
 中文问题 ──> 双语查询改写 ──> BM25 风格检索
                                  ↓
                           Top-K 分页证据
                                  ↓
                     DeepSeek 回答 + 页码白名单
                                  ↓
                     引用校验 + 可点击证据卡
```

## 主要功能

- PDF 拖拽和多选上传、解析进度、文件签名与扫描件检测
- 左原文右译文、学术段落排版、原始图文版面、同步滚动
- 四色原文高亮、Markdown 译文预览与人工修订
- 跨语言查询改写、BM25 风格检索、多轮流式问答
- 页码白名单、生成后引用校验、证据片段卡片
- 结构化摘要、研读笔记、Markdown 导出、2–5 篇论文对比
- IndexedDB 本地文献库与浏览器端 API Key 管理
- 无 Key、无网络也可操作的内置评审样例

## 工程与隐私

- 技术栈：React 19、TypeScript、Vite 8、Tailwind CSS、PDF.js、IndexedDB。
- AI 请求由浏览器直接发送到 DeepSeek，不经过本项目自有服务器。
- PDF、解析文本、译文、标注和对话默认只保存在当前浏览器。
- 当前版本不上传文献到项目服务器，也不包含任何内置 API Key。

## 已知边界

- 扫描版 PDF 目前只检测并提示，需要先做 OCR。
- 图片、表格和公式可在“原始版面”中查看，但视觉语义尚未进入结构化检索。
- 跨语言检索采用本地学术词表和模型改写，仍需公开数据集上的正式评测。
- 内置样例的数字是产品演示数据，不是论文实验结论。

## 数据流安全说明

```text
用户浏览器
 ├─ IndexedDB：PDF、文本、译文、标注、对话
 ├─ sessionStorage / localStorage：用户自行配置的 API Key
 └─ HTTPS 请求：仅在用户主动调用 AI 时直连 DeepSeek
```

请勿在公开仓库提交真实 API Key、含个人隐私的论文或未获授权的数据。
