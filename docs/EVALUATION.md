# 评测方案与当前证据

## 核心假设

作品的价值不是“让回答更长”，而是降低用户核验 AI 结论所需的时间，并减少跨语言检索漏召回和错误页码引用。

## 指标

| 维度 | 指标 | 计算方式 |
|---|---|---|
| 检索 | Evidence Page Recall@K | 标注证据页是否出现在前 K 个检索片段中 |
| 引用 | Citation Validity | 回答引用是否属于本轮检索页白名单 |
| 可用性 | Time to Evidence | 从看到答案到打开正确原文证据所需时间 |
| 忠实度 | Unsupported Claim Rate | 回答中无法由证据片段支持的事实性结论比例 |
| 工程 | Reproduction Success | 新环境能否按 README 在 10 分钟内完成启动与演示 |

## 建议测试集

1. 选择 10 篇中英文开放获取论文，覆盖计算机、医学和工程领域。
2. 每篇由两名标注者编写 8 个问题：创新、方法、数据、结果、局限、参数、结论和追问各 1 个。
3. 至少一半问题与论文语言不同，用于测试跨语言检索。
4. 标注每题的证据页、关键句和“论文未提供答案”的负例。
5. 比较字面关键词基线、本地词表扩展、词表 + 模型改写三种设置。

## 当前自动/人工检查

- TypeScript 类型检查；
- ESLint 静态检查；
- Vite 生产构建；
- 无 Key 演示路径；
- 回答引用白名单与生成后链接校验；
- 证据卡到双语页的跳转；
- 本地持久化恢复。

## 真实性说明

内置演示样例包含的 40 个问题、62.5%、87.5%、18 秒和 51 秒均为**合成演示数据**，用于说明评测界面和指标含义，不作为作品效果证据。正式答辩前应完成上述公开测试集评测，并在报告中提供原始标注、脚本、均值和置信区间。

## 下一步最重要的实验

优先完成 80 个跨语言问题的 Evidence Page Recall@5 对比。它能直接验证作品最核心的技术主张，比继续增加泛化功能更有说服力。
