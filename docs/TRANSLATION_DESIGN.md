# 翻译增强设计

## 参考项目与实现边界

用户指定参考 https://github.com/zotero/zotero 。阅读其 `chrome/content/zotero/xpcom/reader.js` 与 `.gitmodules`，借鉴阅读选区、标注、来源定位和笔记联动的流程。Zotero 的 translators 子项目面向文献元数据抓取；正文翻译是独立能力。本实现使用现有 DeepSeek 服务，没有复制 Zotero 源码。

## 使用方法

1. 双语精读的“智能排版”中选中文字，打开选区翻译面板；可译成中文或英文。单词返回论文语境词义，句段返回对应译文。
2. 通过“高亮原文”保存标注；修改选区译文后，点击“原文与译文存入笔记”，保留页码链接。
3. “术语约定”可为每篇论文保存最多 3000 字符的术语映射；后续整页与选区翻译使用该约定。
4. 整页翻译按不超过 4500 字符的片段顺序处理，显示完成进度；所有片段成功才替换旧译文。失败/取消保留原译文，可手动重试。
5. 切页、切文献或离开阅读器会取消当前页面请求，避免异步结果写进新页面；未完成的译文编辑在离开时保存。

PDF 图像继续通过“原始版面”核对。本次翻译只处理已提取文本与图注；未增加图片视觉翻译或 OCR。术语约定由模型遵循，需要人工核对。

## 验证

`node --experimental-vm-modules --test tests/translation.test.mjs`：完整分段、术语与语言提示、顺序与进度、取消、空结果、SSE 跨帧中文、服务错误和输出截断。

另运行项目 TypeScript 检查、ESLint 和生产构建。浏览器验收使用模拟翻译响应，验证界面、笔记、持久化和切页取消；模拟响应不代表真实翻译质量。
